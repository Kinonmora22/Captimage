manual rápido

Como usar o CaptiMage

Monte uma composição de imagens, ajuste cada detalhe e exporte o resultado sem sair do navegador.

histórico

Voltar e avançar

Desfaça ou refaça alterações feitas na composição.

VoltarCtrl+Z
AvançarCtrl+Shift+Z
começar

Adicionar imagens

Clique em Enviar imagens, arraste arquivos para a página ou cole uma imagem com Ctrl + V.

composição

Ordem e direção

Escolha maior → menor, menor → maior ou ative o modo vertical. No modo vertical, escolha o alinhamento horizontal.

seleção

Selecionar imagens

Clique para selecionar. Use Ctrl para várias imagens e Shift para selecionar um intervalo.

organizar

Reordenar e mover

Arraste uma imagem na prévia ou na lista inferior para mudar sua posição. Use o botão direito na prévia para navegar.

acabamento

Cores e bordas

Configure a cor do vazio, transparência, bordas, raios e espaçamento. Apagar cores permite escolher cores diretamente na prévia.

resultado

Copiar e exportar

Use Copiar para enviar a composição para a área de transferência ou Exportar para salvar um arquivo.

barra superior

Botões principais

+ Adicionar maisInclui outras imagens sem remover as que já estão na composição.
HighlightMarca as imagens selecionadas com a cor de seleção quando forem copiadas ou exportadas.
VerticalAlterna entre composição em fila horizontal e imagens empilhadas verticalmente.
CopiarCopia a composição inteira. Com uma imagem selecionada, Ctrl + C copia somente essa imagem.
ExportarSalva a composição final em PNG e permite escolher nome e local do arquivo.
☾ / ☀Alterna entre o tema escuro e o tema claro.
?Abre este manual de uso.
ordem

Layout e alinhamento

Maior → menor e menor → maior ordenam pela altura das imagens. No modo horizontal, para cima, centralizado e para baixo controlam a posição vertical. No modo vertical, o alinhamento horizontal oferece esquerda, centralizado e direita.

espaço

Espaço e padding

Selecione uma imagem, informe o espaço até a próxima e clique em Aplicar espaço. O padding geral adiciona margem ao redor de toda a composição. Selecionar todos aplica o mesmo espaço a todos os intervalos e pode ser acionado com Ctrl + A.

cores e acabamento

Controles de imagem

Cor do vazio / Cor da bordaEscolhe qual área será editada. O campo HEX, RGB, a superfície de cor e os sliders alteram a cor ativa.
TransparenteRemove a cor ativa e deixa o vazio ou a borda transparente. Clique novamente para voltar à cor escolhida.
Apagar bordasRemove cores conectadas às bordas das imagens selecionadas.
Apagar coresAtiva o conta-gotas. Clique em uma cor dentro da prévia para removê-la das imagens selecionadas.
ResetRemove as cores apagadas das imagens selecionadas. A lista permite selecionar várias cores com Ctrl ou Shift e apagá-las com Delete.
ReescalarCorta o espaço transparente criado pela remoção de cores ou bordas nas imagens selecionadas.
Borda das imagensDefine espessura, raio geral e raios individuais dos quatro cantos.
prévia

Interações rápidas

SelecionarClique rapidamente em uma imagem para selecioná-la. Clicar novamente em uma imagem já selecionada remove a seleção.
Ctrl e ShiftSegure Ctrl para adicionar ou remover imagens individuais. Segure Shift para selecionar todas as imagens entre a seleção atual e a imagem clicada.
Selecionar todosUse o botão Selecionar todos ou Ctrl + A. Pressione novamente para limpar a seleção.
Reordenar na préviaSegure o botão esquerdo sobre uma imagem, mova-a para outra posição e solte para confirmar. A animação de reorganização aparece após o movimento.
Reordenar na listaNa lista de imagens abaixo da prévia, segure um item ou seu ícone e arraste-o até a posição desejada.
Navegar na préviaSegure o botão direito e mova o mouse para deslocar a área da prévia. Ao soltar, a inércia continua o movimento brevemente.
Dois botões juntosÉ possível segurar uma imagem com o botão esquerdo e, sem soltá-lo, usar o botão direito para navegar pela prévia. Os dois comportamentos funcionam ao mesmo tempo.
Roda do mouseUse a roda para rolar a página, a prévia ou a lista de cores conforme a área sobre a qual o cursor estiver. A rolagem é suavizada e acelerada.
Hover e brilhoPassar o mouse sobre uma imagem mostra a borda de seleção. Ao clicar, um brilho rápido confirma a seleção sem sair dos limites da imagem.
atalhos

Teclado e arquivos

Ctrl + ASeleciona todas as imagens. Pressione novamente para retirar a seleção.
Ctrl + CCopia as imagens selecionadas individualmente para a área de transferência do navegador.
Ctrl + VAdiciona imagens coladas depois da última imagem selecionada.
DeleteApaga imagens selecionadas ou, quando a lista de cores estiver focada, remove as cores selecionadas.
Ctrl + ZDesfaz a última alteração. Ctrl + Shift + Z refaz a alteração.
EnterConfirma valores numéricos de espaço, padding, bordas, RGB, HEX e sliders.
EscFecha o manual de uso quando ele estiver aberto.
Arrastar arquivosSolte imagens na página para adicioná-las à composição sem abrir o seletor.
Dica: os ajustes de cor, borda, remoção e reescala afetam somente as imagens selecionadas. O padding continua sendo sempre geral.
